# Demon Duels

**Stake a demon. Seal a move. Take the spoils.** A winner-takes-both card dueler built for MagicBlock Blitz v10: Entertainment Finance.

## Play

- **Play a real devnet duel** sets up a browser guest, requests free devnet SOL if needed, opens a MagicBlock VRF starter pack, and stakes one card against the bot. No wallet extension or real SOL needed.
- **Offchain tutorial** is instant and works without a wallet or RPC. To choose a stake manually or invite a friend, use **Open devnet vault**. If the airdrop is unavailable, fund the guest with about 0.05 **devnet** SOL, never mainnet SOL.
- Keep the same browser profile and deployment URL to retain the guest wallet and its cards.
- Open a starter pack, choose a card, and challenge the bot or send a duel link to a friend. In a friend duel, both players need their own funded guest wallet and card.
- Rend beats Ward, Ward beats Hex, and Hex beats Rend. Each move starts at 2 damage, advantage adds 1, and a 25% crit adds 2. VRF breaks ties. The winner takes ownership of both cards.

Devnet cards have no monetary value. An open challenge can be canceled; once both cards are staked, either player can reclaim their stake after the 30-minute timeout if the duel has not settled.

## How it works

1. **Starter pack.** The Anchor program creates a pack and three card accounts. MagicBlock VRF picks three distinct demon types in an authenticated callback.
2. **Stake.** Each card PDA records its current owner and can be locked to only one duel. The program verifies ownership and prevents a staked card from being reused.
3. **Seal and reveal.** The round and both pick PDAs delegate to MagicBlock’s devnet TEE. Each pick is behind a private permission scoped to its player. The program reveals the moves together, once both are sealed, and commits the public round to Solana.
4. **Settle.** MagicBlock VRF decides crits and ties. Its authenticated callback updates both cards’ owner fields and clears both stake locks in the same transaction. The result links to that transaction in Solana Explorer.

## Develop

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/` is the static deployment output. GitHub Pages can publish it by selecting **GitHub Actions** in the repository's **Settings → Pages**.

Build the Anchor program with `cargo build-sbf` and the Solana SBF toolchain. The browser defaults to MagicBlock devnet and its TEE; set `VITE_BASE_RPC` and `VITE_TEE_RPC` at build time to override them. Do not put private RPC keys in frontend environment variables.

`npm run smoke:devnet` runs a real two-wallet round against the deployed program. It uses a funded devnet signer at `~/.config/demon-duels/deployer.json` and stores the two disposable smoke-test signers beside it. Use `SMOKE_PROFILE` for a new pair or `SOLANA_RPC` to override the base-chain RPC.

Demon art and audio come from [Dust Demons](https://github.com/southenempire/dust_demons). MagicBlock integration follows the [Rock Paper Scissors and Roll Dice examples](https://github.com/magicblock-labs/magicblock-engine-examples).
